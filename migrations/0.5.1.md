# Migration 0.5.1

A bug-fix release from the first tester reports. **This migration does not touch your notes or wiki pages**,
and no setting changes its meaning. The fixes arrive with the regular system-file update (step "replace
`.tools`" in the **update** skill).

This migration does three things: it checks the downloaded kit, generates `AGENTS.md` (and the Codex skills)
again so agents get the updated **import** and **ingest** skills, and runs `brain refresh` once, which now
creates any missing search collection — so a brain whose better search silently stayed off starts using it.

**Placeholders:** put in `<vault>` and `<kit-klon>` as **absolute paths, no `~`** (for example
`/Users/<name>/.brain-kit/kit/v0.5.1` or `C:\Users\<name>\.brain-kit\kit\v0.5.1`), always inside the double
quotes shown below. Every path is passed to Node as an argument, never written into the JavaScript itself.

## What's new for the person

- The better search is found again on macOS and Linux after a fresh install, and its second collection (used
  by the hint before every prompt) is created automatically. `brain doctor` now checks both.
- `brain doctor` and the installer warn when the `voll` search profile runs on less than 16 GB of memory.
- The importer reports far fewer false contradictions (navigation lines, the same link written twice,
  "as of <date>" lines about different things).
- Imports now finish: `brain import fertig <source> <package> --ziel <cluster>` moves an incorporated package
  out of the inbox into its cluster, and `brain pflege` stops reporting it. For an import you already
  incorporated before this release, run it once per package (or with `--alle`).

## Step 1 — Check the release brings the fixes

**Do:** nothing — this step only confirms the downloaded kit is complete before `.tools` is replaced.

**Check:**
```
node -e "const fs = require('node:fs'), p = require('node:path'), k = process.argv[1]; process.exit(['.tools/import/abschluss.mjs', '.tools/qmd-befehl.mjs', '.tools/search-refresh.mjs'].every(f => fs.existsSync(p.join(k, f))) && fs.readFileSync(p.join(k, '.tools', 'qmd-befehl.mjs'), 'utf8').includes('qmdPrivatBin') ? 0 : 1)" "<kit-klon>"
```
**Expected:** exit code `0`.

## Step 2 — Generate AGENTS.md again

**Do:**
```
node "<kit-klon>/.tools/skills-build.mjs" "<vault>" --ziel agents "<vault>/AGENTS.md"
```
Only if the folder `<vault>/.agents/skills` exists (the installer creates it for Codex) — also:
```
node "<kit-klon>/.tools/skills-build.mjs" "<vault>" --ziel agents-skills "<vault>/.agents/skills"
```

**Check:**
```
node -e "process.exit(/brain\.mjs\W+pflege/.test(require('node:fs').readFileSync(process.argv[1], 'utf8')) ? 0 : 1)" "<vault>/AGENTS.md"
```
**Expected:** exit code `0`.

## Done

Set `systemVersion` to `0.5.1` in `brain.config.json` and commit (the **update** skill does this). After
`.tools` has been replaced, run the search refresh once — it creates missing search collections and does
nothing harmful when the better search is not installed or the profile is `minimal`:
```
node "<vault>/.tools/brain.mjs" refresh
```
**Expected:** exit code `0` (without the better search it prints a short note and still exits with `0`).
