# Migration 0.5.0

Nothing in your notes or wiki pages has to change for this release, and no existing setting changes its
meaning — **this migration does not touch your notes or wiki pages** (only, if needed, the explanation in
`_schema.md`, step 4). Everything new — the `fragen` field, the learning loop, the threshold check and the
answer benchmark — arrives with the regular system-file update (step "replace `.tools`" in the **update**
skill). Every new automation that uses AI stays **opt-in** (`antwortMesslatte` is `aus` by default); the
learning loop only runs while the existing `luecken` switch is on (off by default) and uses 0 tokens.

The optional frontmatter field `fragen` and the new setting `antwortMesslatte` need nothing added by hand —
pages without `fragen` keep exactly the same search card as before.

This migration does four things: it checks the downloaded kit, generates `AGENTS.md` (and the Codex skills)
again so agents get the updated **ingest** skill, re-runs the Claude Code adapter if it is installed (the
status line now refreshes every 10 seconds, so idle terminals show changes from other sessions), and adds the
explanation of `fragen` to the vault's wiki schema if it is missing there (the schema is only copied at
install time).

**Placeholders:** put in `<vault>` and `<kit-klon>` as **absolute paths, no `~`** (for example
`/Users/<name>/.brain-kit/kit/v0.5.0` or `C:\Users\<name>\.brain-kit\kit\v0.5.0`), always inside the double
quotes shown below. Every path is passed to Node as an argument, never written into the JavaScript itself.

## What's new for the person

- A wiki page can list the questions it answers, in your own words: `fragen: ["…", "…"]`. They go into the
  page's search card, so the brain hint fires exactly on those questions. The **ingest** skill adds 2–4 when it
  creates or reworks a page; `brain-lint` reports a malformed list as `FRAGEN`.
- **Learning loop** (0 tokens, only with `luecken` on): when your AI reads a wiki page the hint did not name
  shortly after a question, the brain remembers "question → page" and, once a week, suggests at most five of
  these pairs as `fragen` for that page. `brain lernschleife` lists the candidates.
- **Threshold check:** `brain analyse` (and the Analysis tab) now says whether the hint is too strict (it
  stayed silent, but a page was read right after) or too loose (it named pages nobody read), and recommends a
  level — never changed automatically.
- **Answer benchmark** (opt-in, `antwortMesslatte: monatlich`): once a month a lean Haiku call answers your
  test questions from `<wiki>/_antworten.json` using only the named page; the key facts are checked locally.
  By hand: `brain antworten`.

## Step 1 — Check the release brings the learning loop

**Do:** nothing — this step only confirms the downloaded kit is complete before `.tools` is replaced.

**Check:**
```
node -e "const fs = require('node:fs'), p = require('node:path'), k = process.argv[1]; process.exit(['.tools/fragen.mjs', '.tools/lernschleife.mjs', '.tools/antwort-messlatte.mjs', '.tools/brain-stand.mjs'].every(f => fs.existsSync(p.join(k, f))) ? 0 : 1)" "<kit-klon>"
```
**Expected:** exit code `0`.

## Step 2 — Generate AGENTS.md again

**Do:**
```
node "<kit-klon>/.tools/skills-build.mjs" "<vault>" --ziel agents "<vault>/AGENTS.md"
```
Only if the folder `<vault>/.agents/skills` exists (the installer creates it for Codex) — also:
```
node "<kit-klon>/.tools/skills-build.mjs" "<vault>" --ziel agents-skills "<vault>/.agents/skills"
```

**Check:**
```
node -e "process.exit(/brain\.mjs\W+pflege/.test(require('node:fs').readFileSync(process.argv[1], 'utf8')) ? 0 : 1)" "<vault>/AGENTS.md"
```
**Expected:** exit code `0` (the new AGENTS.md still knows `brain.mjs" pflege`).

## Step 3 — Register the new Claude Code hooks (only if Claude Code is connected)

The adapter is idempotent and safe to re-run even where nothing changed for a given vault; doing it now
adds the 10-second refresh to the brain status line (a refresh interval you set yourself is kept). Skip this step — including its check — if the first check below exits with `1` (no Claude Code adapter
installed, e.g. with Codex, Gemini or Cursor).

**Check whether the adapter is installed:**
```
node -e "const f = require('node:path').join(require('node:os').homedir(), '.claude', 'commands', 'brain-update.md'); const fs = require('node:fs'); process.exit(fs.existsSync(f) && fs.readFileSync(f, 'utf8').includes('brain-kit -->') ? 0 : 1)"
```
**Exit code `0`** → **Do:** run the adapter from the new release (merges its hooks into
`~/.claude/settings.json` with a backup and never touches other hooks or your own commands):
```
node "<kit-klon>/.tools/adapters/claude-code/install.mjs" "<vault>"
```

**Check:**
```
node -e "const f = require('node:path').join(require('node:os').homedir(), '.claude', 'settings.json'); const s = require('node:fs').readFileSync(f, 'utf8'); process.exit(s.includes('ernte-ausloeser.mjs') && s.includes('session-start.mjs') ? 0 : 1)"
```
**Expected:** exit code `0` (`settings.json` still carries exactly one entry for each hook — re-running
never duplicates them).

## Step 4 — Explain the new field in the wiki schema (only if missing)

`_schema.md` in the wiki folder was copied once at install time, so existing vaults don't explain `fragen` yet.
This step appends the paragraph from the new template — only if the schema exists and does not mention
`fragen:` yet (running it twice changes nothing).

**Do:**
```
node -e "const fs = require('node:fs'), p = require('node:path'), [v, k] = process.argv.slice(1); let c = {}; try { c = JSON.parse(fs.readFileSync(p.join(v, 'brain.config.json'), 'utf8')); } catch {} const ziel = p.join(v, (c.ordner && c.ordner.wiki) || (c.wiki && c.wiki.ordner) || '09_wiki', '_schema.md'); if (!fs.existsSync(ziel)) process.exit(0); const s = fs.readFileSync(ziel, 'utf8'); if (s.includes('fragen:')) process.exit(0); const m = fs.readFileSync(p.join(k, 'vorlage', 'wiki', '_schema.md'), 'utf8').replace(/\r\n/g, '\n').match(/^- \x60fragen:[\s\S]*?(?=\n- |\n\n|\n##)/m); if (!m) process.exit(1); fs.writeFileSync(ziel, s.trimEnd() + '\n\n## Fragen (seit 0.5.0)\n' + m[0] + '\n');" "<vault>" "<kit-klon>"
```

**Check:**
```
node -e "const fs = require('node:fs'), p = require('node:path'), v = process.argv[1]; let c = {}; try { c = JSON.parse(fs.readFileSync(p.join(v, 'brain.config.json'), 'utf8')); } catch {} const ziel = p.join(v, (c.ordner && c.ordner.wiki) || (c.wiki && c.wiki.ordner) || '09_wiki', '_schema.md'); process.exit(!fs.existsSync(ziel) || fs.readFileSync(ziel, 'utf8').includes('fragen:') ? 0 : 1)" "<vault>"
```
**Expected:** exit code `0` (either the schema now explains `fragen`, or there is no schema to update).

## Done

Set `systemVersion` to `0.5.0` in `brain.config.json` and commit (the **update** skill does this). After
`.tools` has been replaced, one run confirms the new pieces load:
```
node "<vault>/.tools/brain.mjs" lernschleife
```
**Expected:** exit code `0` (with `luecken` off or no history yet it simply reports that there are no
candidates).
