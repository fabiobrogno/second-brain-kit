# Migration 0.1.0

This is the first kit release. There's no older `systemVersion` to migrate *from* within the kit itself —
this migration instead covers moving an **existing, hand-built brain** (one predating this kit, with its
own ad-hoc `.tools/` and git hooks) onto the kit's structure. If you're installing fresh with `install.mjs`
or the bootstrap scripts, none of this applies — `systemVersion` is already `0.1.0` and `AGENTS.md` is
already generated for you.

Run each step in order. Commit before each one (the skill `update` already does this for you if you're
following it from there). Never touch note or wiki content in any of these steps — only system files.

## Step 1 — Remove old, hand-installed git hooks

Old setups may point `core.hooksPath` somewhere other than the kit's own `.tools/git-hooks`, or have hooks
installed directly under `.git/hooks/` instead.

**Do:**
```
node .tools/install-git-hooks.mjs "<vault>"
```
This sets `core.hooksPath` to `.tools/git-hooks` unconditionally (idempotent — safe to re-run).

**Check:**
```
git -C "<vault>" config core.hooksPath
```
**Expected:** `.tools/git-hooks`

## Step 2 — Rename your old team-knowledge module key to `module.teamWissen`

A pre-kit, hand-built config may have had its own, custom-named boolean for an external team knowledge
base integration (whatever it was called in your own setup). The kit's generic name for this optional
module is `module.teamWissen` (off by default, opt-in only).

**Do:** in `<vault>/brain.config.json`, find that old key under `module` (it won't be one of the kit's
known names — `teamWissen`, `claudeMemory`, `youtubeIngest`, `githubBackup`), copy its value to
`module.teamWissen`, and remove the old key. Leave every other key untouched.

**Check:**
```
node -p "const c = require('<vault>/brain.config.json'); const bekannt = ['teamWissen','claudeMemory','youtubeIngest','githubBackup']; JSON.stringify({ unbekannteSchluessel: Object.keys(c.module||{}).filter(k => !bekannt.includes(k)), teamWissen: c.module?.teamWissen })"
```
**Expected:** `{"unbekannteSchluessel":[],"teamWissen":true|false}` (whatever the old value was).

## Step 3 — Generate AGENTS.md

Older setups may not have a vault-root `AGENTS.md` at all (the kit renders it fresh every session from
`.tools/kit/AGENTS.md` — it's gitignored, never hand-edited).

**Do:**
```
node .tools/skills-build.mjs "<vault>" --ziel agents "<vault>/AGENTS.md"
```

**Check:**
```
node -e "process.exit(require('node:fs').existsSync('<vault>/AGENTS.md') ? 0 : 1)"
```
**Expected:** exit code `0`.

## Done

Set `systemVersion` to `0.1.0` in `brain.config.json` and commit:
```
node -e "const f='<vault>/brain.config.json', c=JSON.parse(require('fs').readFileSync(f,'utf8')); c.systemVersion='0.1.0'; require('fs').writeFileSync(f, JSON.stringify(c,null,2)+'\n')"
```
Then run `node .tools/brain.mjs doctor` once — no `FEHLT` line means the migration is complete.
