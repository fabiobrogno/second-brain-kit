## [0.1.0] - 2026-10-02 (Preview)
- First public preview of the Second Brain Kit.
- Works on macOS, Windows and Linux; one sentence to your AI app sets it up (no admin rights, no terminal typing).
- Agent-neutral: `AGENTS.md` + skills for Claude Code, Codex, Gemini CLI and Cursor; Claude Code adapter with hints, status line and wiki guard.
- Correct knowledge: evidence-bound wiki pages (source hash + revision), visible contradiction boxes, freshness lint, secrets gate in pre-commit.

- CI on macOS, Windows and Linux.
