# Tomaten pflanzen

Tomaten brauchen einen sonnigen und windgeschützten Platz im Garten. Die jungen Pflanzen kommen erst nach den Eisheiligen ins Beet, wenn die Nächte warm genug sind. Beim Pflanzen setzt man sie etwas tiefer in die Erde, dann bilden sie zusätzliche Wurzeln am Stängel. Ein stabiler Stab oder eine Spirale gibt Halt, sobald die Früchte schwer werden. Gegossen wird immer direkt an der Wurzel und nie über die Blätter, damit keine Pilzkrankheiten entstehen. Seitentriebe in den Blattachseln regelmäßig ausgeizen. Eine Mulchschicht aus Rasenschnitt hält den Boden feucht.
